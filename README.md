A professional portfolio website developed for **Marialena Zafeiriou**, showcasing projects in fashion design, fashion illustration, styling, and trend forecasting through a modern, responsive, and interactive user experience.

---

## Overview

The project is a static single-page web application built with modern front-end technologies. It combines elegant visual presentation with responsive layouts and interactive components to create an engaging digital portfolio.

---

## Features

### PDF Portfolio Viewer

The application integrates **PDF.js** to render portfolio documents directly in the browser.

Features include:

- Client-side PDF rendering
- Previous / Next page navigation
- Page counter
- Lazy loading
- Loading indicators
- Error handling

---

### Splash Screen

A custom loading screen is displayed while portfolio assets are initialized.

- Dynamic loading messages
- Smooth loading animations
- Improved loading experience

---

### Interactive Project Panels

Projects are presented through responsive modal windows.

Features:

- Interactive project previews
- Smooth open/close animations
- Click outside to close
- Responsive layout

---

### Responsive Design

The application is fully optimized for:

- Desktop
- Laptop
- Tablet
- Mobile

Additional functionality:

- Orientation detection
- Portrait mode recommendation
- Responsive typography
- Adaptive layouts
- Flexible image scaling

---

### Contact Form

The contact form is powered by **FormSubmit** without requiring a backend server.

Features include:

- Email delivery
- Automatic confirmation email
- Custom email subject
- Spam protection
- Redirect to a custom thank-you page

---

### UI Animations

Custom CSS animations enhance the browsing experience.

Implemented animations include:

- Stitch-inspired decorative effects
- Smooth page transitions
- Hover effects
- Loading animations
- Modal animations

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/fashion-portfolio.git
```

Navigate to the project directory:

```bash
cd fashion-portfolio
```

Open **index.html** using any modern web browser.

No build tools or package installation are required.

---

## Deployment

This is a static website and can be deployed on any static hosting platform, including:

- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting

When deploying, ensure the directory structure remains unchanged, particularly the `img/` and `pdf/` folders, to preserve correct asset references.
